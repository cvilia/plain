## 1. 一句话方向

**Quiet Ledger — 安静的账本。**

把界面做成一本**装订干净的账册**：纸是冷的近真白，格子是发丝线，唯一的黑是数字。
没有底色、没有光、没有盒子套盒子。所有视觉预算都给**金额排印**。

不是：暖纸手账 / 仪表盘 / 理财模板 / Material 默认主题。

| 参考 | 学它什么 | 不学什么 |

## 3. 四条定调（逐条可验收）

### 定调 1 · 中性层干净，不要暖

- 亮态：`bg #F5F5F6` → `appBg #FBFBFC` → `surface #FFFFFF` → `surface2 #F6F6F8`。
  **surface 是真白**，不是奶白；`bg` 的 R/G/B 差 ≤1（零色偏）。
- 暗态：`bg #121214` → `appBg #1A1A1D` → `surface #222225` → `surface2 #2B2B2F`。
  最深处是 `#121214`，**不是 `#000`**；文字是 `#ECECEE`，**不是 `#FFF`**。
- 灰阶 6 级：`ink / ink2 / muted / faint` 四级文字灰 + `line / lineSoft` 两级结构线。
- 三个 tone 只做 ≤2 个 RGB 单位的冷/暖偏（`cool` / `neutral` / `sand`），**不足以形成米黄**。
  量测：`sand` 亮态 `bg #F7F6F4`，R−B = 3；上一版是 R−B = 2 但 surface 是 `#FFFEFB`（4 单位）且卡片另有米色 → 叠加成米黄。

### 定调 2 · 数字是唯一主角

- 一屏只允许一个 34px 以上的数字；它是全屏对比度最高、字重最重、字号最大的元素。
- 金额专用排印（三条同时生效）：
  1. **tabular-nums 强制开启**（否则两行金额的小数点对不齐）；
  2. **千分位逗号**一律加（`¥12,345.67`）；
  3. **小数与货币符号弱化到 0.62× 字号 + `muted` 色**，整数位 700 字重 ——
     这是本产品的签名记忆点：「一眼看到整数，需要时才看小数」。
- 非金额的界面文字全部 ≤ 22px，且最高只到 600 字重。

### 定调 3 · 结构靠线与留白，不靠盒子

- 列表**不是**行行卡片：一个分组 = 一块 `surface` 面板 + 组内 `1px lineSoft` 分隔线；
  行自身没有任何填充、圆角、阴影。
- 分组之间靠 **32px 留白 + 一条 `1px line`** 断句，不靠再加一层卡。
- 圆角**只有 4 档**：`8 / 12 / 16 / 24`（+ 全圆）。没有第 5 个值。
- 阴影**只有 3 档**，且默认卡片用 `e1`（`0 1px 2px`）——是「一张有边界的纸」，不是「浮起的板」。
- 上一版的「结余卡 + 柔光渐变」整块删除：**结余区是纯排印 + 发丝线**，没有面板、没有渐变、没有光斑。

### 定调 4 · 色彩是语义，不是装饰

- 一屏彩色面积 **≤ 15%**（实测最大的「报表」屏为 11.4%，见 §7）。
- 12 个分类色**只出现在三个位置**：环形图扇区、列表行左侧 6px 圆点、选中分类格的描边。
  **没有「淡彩圆角方块托图标」**——这正是上一版最像模板的一处。
- 品牌强调色（素白 = 橘红 `#FB923C`）一屏只出现在**一个动作**上：FAB 或主按钮。
- 红=进账、绿=下跌/节省（中文金融习惯，与欧美相反）；语义色跨 10 主题恒等（INV-1）。

## 5. 签名记忆点（三处，用户能闭眼描述出来）

1. **金额的节奏**：整数位重、千分位有呼吸、小数位退到灰色小字。
   一屏只出现一次的那个大数字，就是品牌的「脸」。
2. **发丝线账页**：分组之间一条 `1px` 线 + 32px 留白；行与行之间一条更淡的线。
   整屏找不到一个「卡片套卡片」。
3. **键帽键盘**：数字是**按下去的**，不是漂在空白上的。底部固定 4×4，右手拇指可达全部按键；
   操作列（⌫ / OK）用沟槽与数字区隔开。

## 6. 放弃清单（本版明确不做）

| 放弃项 | 原因 |
| --- | --- |
| 任何渐变面板 / 光斑 / 模糊光晕 | 上一版最大污点；层级应由排印与留白承担 |
| 衬线、楷体、手写体 | 与数字界面气质冲突，且显廉价 |
| 图标底衬色块（每个图标一个淡彩圆角方块） | 模板脸；图标靠光学重量而非底色被识别 |
| 行行卡片 / 每行独立圆角与阴影 | 结构应由线承担；卡片多了层级反而更弱 |
| 完整彩色分类胶囊 | 一屏彩色面积失控；分类色退到 6px 圆点 |
| `heroGrad*` 渐变令牌的实际使用 | 令牌保留（门禁需要），但 v3 全产品不使用 |
| 徽章 / 成就墙 / 打卡日历等装饰性视觉 | 与「安静的账本」冲突；且属 V2.0 之后的产品决策 |
| 纯黑（`#000`）与纯白（`#FFF`）文字 | 亮态文字用 `#101012`，暗态用 `#ECECEE` |

## 7. 可验收指标（本版交付时已实测）

| 指标 | 目标 | 实测 |

| 一屏彩色面积 | ≤ 15% | 最大 11.4%（报表屏环形图） |
