## 3. 面板 1 · 与上月对比

```
.panel.cmppanel{padding:18px 16px 10px}
.eyebrow 12/600 字距+0.08em muted  「与上月对比」
.crow{display:flex;height:44px;gap:12px;align-items:center}
   ├ .ck  flex:1        15/500 ink        「支出」
   ├ .cv  amount-s      15/600 tnum       ¥5,879.50
   └ .cd  flex:0 0 76   12/600 + 箭头      ↗ 12.4%
```

| 行 | 值 | 方向色 |
| --- | --- | --- |
| 支出 | ¥5,879.50 | `tone-up`（红）↗ 12.4% |
| 收入 | ¥+9,300.00（`tone-income`） | `tone-up`（红）↗ 8.1% |
| 结余 | ¥3,420.50 | `tone-dn`（绿）↘ 6.2% |

⚠️ **涨跌色一律「涨红跌绿」，与行标签的语义无关**。方向由**箭头图标**承担，颜色只表达涨跌。
首版把「支出 ↗」写成中性灰、把「收入 ↗」写成红，同一屏出现两套色彩逻辑，**已返工统一**。

> 这是中国记账/证券惯例（涨红跌绿）。**不要**按「支出变多=坏事」反推颜色 ——
> 那会得到「支出红、收入也红」的歧义，且与用户既有心智冲突。

## 4. 面板 2 · 分类占比（环形图）

```
.chartpanel{padding:18px 16px 16px}
.donut-wrap{display:flex;justify-content:center;padding:4px 0 14px}
.donut  136×136   R=52  stroke-width=13  stroke-linecap=butt
       → 环外半径 58.5 / 内孔半径 45.5 / **内孔直径 91.0**
.dn-c1  四段式（整数 18/600 ink tnum；¥ 与小数 .62em muted），基线 y=64
.dn-c2  8.5/600 字距+0.1em fill=muted 「TOTAL」，基线 y=84
```

段与段之间**用 `butt` 端帽**（不圆角），分隔靠留白而不是描边 —— 圆角端帽会让相邻段挤在一起。

### 4.1 ⚠️ 中心金额的宽度硬约束（**首版返工过，别再踩**）

首版环小（124 / R=46 → **内孔只有 79px**）、中心金额走单行 17px 无四段式，
实测 bbox **84.00px > 79** → **文字压在圆环上，暗态尤其明显**。
最坏情况 `¥86,420.50` 更是 **96.00px**，溢出 17px。

修法两条同时上，缺一不可：

| # | 改动 | 数值 |
| --- | --- | --- |
| ① | 把环放大 | `124 / R=46` → **`136 / R=52`**（内孔 79 → **91**） |
| ② | 中心金额改走**全站四段式** | 整数 18px / `¥` 与小数 `.62em` |

**可用宽 = 内孔 91 − 左右各 2 = 87.0px**。实测（`_build/_probe_donut_live.py`，浏览器 `getBBox`）：

| 值 | 档位 | 实测宽 | 判定 |
| --- | --- | --- | --- |
| `¥5,879.50` | 18px | **77.53** | ✅ 左右各余 6.73 |
| `¥86,420.50` | 18px | 83.70 | ✅ |
| `¥999,999.99` | 16px | 83.90 | ✅ |
| `¥9,999,999.99` | 14px | 85.80 | ✅ |
| `¥99,999,999.99`（金额上限） | 12px | 80.60 | ✅ |

⚠️ **超长值向下取档**（18 → 16 → 14 → 12），与首页大金额同一条规则 —— **绝不截断**。
数字按 **tnum 594/1000** 计；比例宽度下 `0` 是 661，会算少约 11%。

> 12px 已接近 `caption` 下限，且 `Money.maxCents` 封顶才有此值。若产品允许展示到上限，
> 建议改用「万/亿」量级缩写 —— 见《10-CHANGELOG》待拍板 **T-9**。

.lrow{display:flex;height:40px;align-items:center}

### 4.4 图例必须封顶（分类数量不设上限）

一行一类的写法有个硬伤：**分类数量是用户自定的**（预设就 12 个一级 / 41 个二级），
原样铺开会把这块面板**无限拉长** —— 20 类 ≈ 20 × 31pt ≈ 620pt，
一个「分类占比」把整屏吃掉（2026-10-16 用户报的）。

口径：

| 项 | 值 |
| --- | --- |
| 默认显示 | **前 5 条**（= 本原型里的行数 → 默认高度恒定） |
| 折叠入口 | 末尾一行「**展开其余 N 类 ▾**」/ 展开后「**收起 ▴**」，**14**/500 `muted` 居中（字阶只有 44/34/22/20/15/14/12，**别用 13**） |
| 出现条件 | 仅当 `段数 > 5`（刚好 5 条时不出现） |
| 展开态 | 全部列出（用户主动展开，不做内部滚动 —— 外层页面已经是滚动容器） |
| 复位 | 钻进某一类 / 返回上级时折叠态复位（段集合整个换了） |

```
.legend-more{display:flex;justify-content:center;align-items:center;gap:4px;
             padding:8px 4px;font-size:14px;font-weight:500;color:var(--muted)}
```

⚠️ 不要改成「内部滚动」：`ListView` 套 `ListView` 在手机上极难操作，
而且外层 `.scroll` 已经负责滚动。

`.lpct` 定宽 48、`.lamt` 定宽 92，两者右对齐 → 百分比与金额各成一条竖线。

## 7. 暗态要点

- 环形图分段色用**同一组分类基色**（INV-1 恒等），暗态不换色 —— 分类色本身在暗底上足够亮。
- `chart-track` 从 `#C2C2C6` 降到 `#4C4C52`，否则在深底上会「发光」。
- 涨跌色在暗态：`tone-up` = `income-ink #FDA4AF`，`tone-dn` = `dn-ink #6EE7B7`，均为提亮变体。
