## 1. 屏幕任务

一眼看到**本月结余**，三秒内找到并打开任意一笔账，或一键进入记一笔。
首页**不承担分析职责**（那是报表页的事），也不出现任何**理财/广告/推荐**内容。

## 3. 区块 3 内部：Hero（本屏的签名区）

```
.hero{padding:14px 0 0}
├ .hero-label   12/600 字距 +0.08em 大写   muted   margin:16 0 8 2   →  「本月结余」
├ .hero-amt     amount-xl 34/700 tnum      ink     margin:0 0 16     →  ¥3,420.50
└ .hero-split   flex gap 28 padding:0 0 16
   ├ .hs  → .hs-l 「支出」12/600 muted  +  amount-s ¥5,879.50
   └ .hs  → .hs-l 「收入」12/600 muted  +  amount-s ¥+9,300.00（tone-income）
```

**Hero 区没有卡片、没有渐变、没有光晕、没有圆角底。** 只有上下 `hairline` 与纯排印。
这是「安静的账本」方向最直接的体现，也是与上一版最大的一处差别。

### 金额四段式（必须照做）

| 段 | 类 | 字号 | 字重 | 颜色 |
| --- | --- | --- | --- | --- |
| 货币符 `¥` | `.cur` | 0.62em | 600 | `muted` |
| 整数 `3,420` | `.int` | 1em | 700 | `ink` |
| 小数点 `.` | `.pnt` | 1em | 700 | `ink` |
| 小数 `50` | `.dec` | 0.62em | 600 | `muted` |

> ⚠️ **必须带 `font-variant-numeric: tabular-nums`**（页面已在 `html,body` 全局开启）。
> MiSans 的 `1` 只有 `0` 的 63% 宽，不开 tnum 两行金额小数点对不齐。见《02-TYPE-SYSTEM》§1。

## 4. 区块 3 内部：日期分组 + 流水行

```
.grp{margin-top:32px}                     分组之间 32，靠留白分组，不靠盒子
├ .eyebrow  12/600 字距+0.08em muted     「9月28日 周日」（英文 Sep 28, Sun 自动大写）
└ .panel    radius 16 / bg surface / border 1px line / overflow hidden
   ├ .row   min-height 60 / padding 9 16 / gap 10
   │  ├ .dot8   8×8 圆点，颜色 = --cat-{ref}      ← 分类只用一个色点
   │  ├ .rcol   flex:1 列
   │  │  ├ .rt   15/500 ink     「餐饮」         ellipsis
   │  │  └ .sub  12/500 muted   「午餐 · 公司楼下」 ellipsis
   │  └ .rw-amt 15/600 tnum     「32.00」        右对齐
   └ .row + .row { border-top:1px solid line-soft }
```

**流水行是本设计系统的纪律样本**：

- ❌ 不套淡彩圆角图标底板（上一版的失败点）
- ❌ 不给行上底色
- ✅ 分类只由 **8×8 色点**表达，图标留给**分类选择器**（见 `03-add.md`）
- ✅ 行与行之间只用 **1px `line-soft`**，分组之间只用 **32px 留白**
- ✅ 金额右对齐 + tnum，形成一条**隐形的金额列**

> 为什么行内用点、选择器用图标：流水行是**扫读**场景，图形会抢金额的注意力；
> 选择器是**辨认**场景，图标能显著降低找分类的时间。同一套 12 色，两种用法。

## 7. 暗态要点

- **不做 invert**。`appBg #1A1A1D` / `surface #222225` / `surface2 #2B2B2F` / `ink #ECECEE`。
- 面板与背景的明度差靠 `layerstep` 门禁保证（≥1.02），另加 **1px `line`** 双保险 —— 暗态下**线比影可靠**。
- 分类色点在暗态用**同一组基色**（INV-1 恒等），不用 `cat-ink`（那是给浅底用的深色变体）。
- `shadow-accent` 在暗态降到 `#00000075` 级别，FAB 不发光。

## 8. 验收点

- [ ] 结余金额在 `standard / large / xlarge` 三档下都不与「支出/收入」两列换行冲突
- [ ] 最长英文次行（`Lunch · Office canteen`）在 358dp 内截断而非撑破
- [ ] 亮/暗两态下 `.row` 的分隔线都可见（≥3:1 图形对比）
- [ ] 色点在暗态下与 `surface` 的对比度 ≥3:1
- [ ] 首页 Hero 区**没有任何卡片/渐变/光晕**（这是硬否决项）
