## 0. 全屏共用骨架

画布 **390 × 844**（iPhone 14/15 逻辑分辨率）。以下三块在多数屏出现，尺寸固定：

| 区块 | 高度 | 说明 |
| --- | --- | --- |
| `.statusbar` | **47** | 时间 14.5/600 + 信号电池；`padding: 0 22 6`，底部对齐 |
| `.topbar` | **56** | 左 `iconbtn` **44×44** + 标题 20/600 居中 + 右 `tb-right`（`min-width:44`） |
| `.nav` | **60** | 5 格，每格 `flex:1` = **78** 宽；中间 `.navfab` **44×44 / r14** |

⚠️ **两条曾踩过的坑**

1. **`iconbtn` 曾经是 40×40**（不足 44 最小触控），已改 **44×44**。
   `textbtn`(34)、`segi`(30)、`switch`(28) 视觉仍小于 44，
   靠 `::after` 透明覆盖层把**命中区**撑到 44 —— 见 `05-COMPONENT-SPECS.md` §24。
2. **`@media (max-width:520px){.frame{transform:scale(.82)}}`** 是页面自身的窄屏兜底。
   用无头浏览器截图时必须用 `!important` 抵消，否则一帧会被缩到 320×692、下缘留 152px 空白。
   `_build/shoot.py` 已处理。

## 1. 高度预算的分工（重要）

八屏分两类，决定了「溢出」是不是 bug：

| 类型 | 屏 | 结构 | 溢出判定 |
| --- | --- | --- | --- |
| **滚动型** | 首页 / 报表 / 资产 / 分类 / 详情 / 设置 | 中部 `.scroll{flex:1}` | 内容高于可视区是**正常**，滚动即可 |
| **固定型** | 记一笔 | 键盘必须常驻贴底 | **任何溢出都是 bug** |

记一笔是唯一「固定型」屏幕，因此它的预算被严格控到 **844 / 844**，
中段 `.addbody{flex:1;overflow-y:auto}` 只作特大字号与英文的安全网。

## 2. 暗态与中英

- 每屏都要出 **亮 × 暗** 两态，暗态**不是 invert**，靠 `surface → surface2 → appBg` 明度分层。
- 每屏都要过 **中 × 英** 两语，英文比中文长 30–100%，`07-SCREENS.html` 可一键切。
- 每个 `text-overflow:ellipsis` 的容器都要用**英文最长串**验一遍。
