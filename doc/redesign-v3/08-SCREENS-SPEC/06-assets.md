### 4.1 数值必须自洽（已验算）

```
52,180.30 + 1,240.20 + 38,000.00 − 5,000.00 = 86,420.50  ✅ = 净资产
```

**演示数据也必须是真算出来的。** 净资产与构成对不上，会直接让实现者以为可以随便填。

### 4.2 账户图标的选择纪律

- 图标走 `ui` 分类（`ic_card` / `ic_wallet` / `ic_chart_line` / `ic_receipt`），**不复用分类图标**。
  首版把信用卡用了 `ic_cat_shopping`（购物袋），语义完全错位，**已返工**。
- 图标一律 **`ink-2` 中性色**，不上分类色、不上品牌色 —— 资产行的重点是数字。

## 5. 负债的呈现

- 负债放在**独立分组**「负债」（`.grp` + `.eyebrow`），不与资产混排。
- 金额带显式负号：**U+2212 `−`**，不是 ASCII 连字符 `-`。
- 颜色保持 `ink` **中性**，依赖符号而非颜色表达正负。

> 为什么不给负债上红/绿：本系统把红绿**专用于涨跌**（见《05-reports》§3）。
> 负债是**状态**不是**变动**，用红会与涨跌语义混淆。
> 符号 `−` 已经无歧义，**色彩是语义不是装饰**，不该在这里多花一次。

## 6. 隐藏金额（顶栏右侧）

`ic_eye_off` → 点击后所有金额变为 `••••••`。

- 对应基础设置 `hide_amount`，属于隐私保护（地铁上记账）。
- 隐藏态下**金额占位宽度保持**（用 `···` 等宽字符），避免布局跳动。
- 图标在开/关两态切换 `ic_eye` / `ic_eye_off`，`aria-pressed` 同步。

## 8. 暗态要点

- 账户图标 `ink-2 #C2C2C7` 在 `surface #222225` 上对比度充足 ✅。
- 面板外框仍是 `line` 1px；暗态下**不要**增加阴影层次（越加越脏）。
- `ic_eye_off` 与 `ic_shield` 在暗态用 `ink-2`，不用 `ink` —— 顶栏图标是功能件不是标题。
