## 1. 间距：4 基数

| 令牌 | 值 | 语义 |
| --- | --- | --- |
| `s1` | 4 | 图标与文字之间、chip 内边距、小数点与数字 |
| `s2` | 8 | 同行元素之间、列表行上下内边距、双行文本行距 |
| `s3` | 12 | 按钮内边距、紧凑卡片内边距、相邻按钮间距 |
| `s4` | 16 | **默认卡片内边距、页面左右边距（手机）** |
| `s5` | 20 | 同一区块内的子块间距 |
| `s6` | 24 | 区块间距、页面顶部留白（平板左右边距） |
| `s7` | 32 | **分组断句留白**（配合 1px 线） |
| `s8` | 40 | 空态与引导页留白 |
| `s9` | 48 | 大留白（引导页、空态上下） |
| `s10` | 64 | 引导页顶部 |

**节奏规则**
1. 组间留白 ≥ 组内间距 × 1.5。
2. **同一屏最多出现 3 个不同间距值**（不同的「块」之间）。超出说明层级没想清楚。
3. 断句用 `s7(32)` + 1px `line`，**不再加一层容器**。

### 1.1 语义间距

| 语义 | 值 |
| --- | --- |
| 页面左右边距 `pagePadH` | 手机 16 / 折叠与小平板 24 / 平板 32 |
| 页面顶部内边距 `pagePadTop` | 12（顶栏另外算，见 §5） |
| 区块间距 `sectionGap` | 32 |
| 分组间距 `groupGap` | 20 |
| 行内间距 `inlineGap` | 8 |
| 卡片内边距 `cardPad` | 手机 16 / 平板 20 |

## 2. 圆角：4 档 + 全圆

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `r1` | **8** | Chip、小标签、图标底衬、图表柱条 |
| `r2` | **12** | 按钮、输入框、分段控件、**数字键盘键帽** |
| `r3` | **16** | 面板、卡片、列表分组、FAB |
| `r4` | **24** | 底部抽屉顶部两角、模态、Toast（竖屏底部） |
| `pill` | **999** | 分类图标圈、开关轨道、分段选中滑块、头像 |

**禁令**：全项目只允许出现这 5 个圆角值。`14` / `18` / `30` 这类「差一点」的值属于缺陷。

## 3. 描边与分隔

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `hairline` | **1** | 分组分隔线、面板边界（= 物理 1px，不随 DPR 变粗） |
| `control` | **1** | 输入框、次按钮、键帽、开关轨道边界 |
| `strong` | **1.5** | 选中态描边（分类格、分段选中） |
| `focus` | **2** | 焦点环（外扩 2px 偏移） |

| 场景 | 色 token |
| --- | --- |
| 分组内分隔线 | `lineSoft` |
| 分组 / 面板边界 | `line` |
| 控件边界（需 ≥3:1） | **`lineStrong`**（不是 `line`！`line` 只有约 1.2:1） |
| 选中态描边 | `primaryInk`（低一档用 `lineStrongSoft`） |
| 焦点环 | `focusRing`（= `primaryInk`） |

> ⚠️ `line` 与 `lineStrong` **不可互换**。发丝线承担「结构暗示」，不需要 3:1；
> 而输入框边框是可交互组件的**唯一可见边界**，WCAG 1.4.11 要求 ≥ 3:1，必须用 `lineStrong`。

## 4. 阴影：3 档，且是冷黑

| 档 | 偏移 | 模糊 | 亮态 alpha | 暗态 alpha | 用途 |
| --- | --- | --- | --- | --- | --- |
| `e0` | — | — | — | — | 平铺内容、列表行、分组面板 |
| `e1` | `0 1px` | 2 | 0.06 | 0.26 | 卡片、按钮静置 |
| `e2` | `0 4px` | 14 | 0.10 | 0.34 | 悬浮按钮、下拉、粘性头 |
| `e3` | `0 18px` | 44 | 0.16 | 0.46 | 模态、抽屉、Toast |

规则：
1. **亮态阴影是冷黑**（`rgb(0,0,0)`），不是暖黑 —— 暖黑在近真白底上会发脏。
2. **暗态降权**（面重于影）：靠 `surface → surface2 → appBg` 的明度层级表达纵深，阴影只做辅助。
3. 暗态面板补一条 **1px `glowPrimary` 内高光**（顶部边缘），替代亮态阴影的「顶部受光」暗示。
4. `e0` 与 `e1` 的区分**不用阴影大小**，用 1px `line` 边界。

## 5. 安全区与顶栏 / 底栏

### 5.1 安全区

| 区域 | 处理 |
| --- | --- |
| 状态栏 | 顶栏高度 = 44 + `safeAreaTop`；顶栏底色 = `appBg`（与页面同底，不做独立色条） |
| 底部手势条 | 所有固定底栏（导航 / 保存条 / 键盘）在 `safeAreaBottom` 之上再加 8px |
| 刘海 / 挖孔 | 横向不做特殊处理；内容一律不进入状态栏垂直区域 |
| 平板圆角 | 不额外留边（系统已给 insets） |

### 5.2 关键固定高度

| 元素 | 高度 | 说明 |
| --- | --- | --- |
| 顶栏 `navBar` | **56** | 不含状态栏；返回键 40×40 热区 44×44，左边距 8（光学对齐 16） |
| 底部导航 `tabBar` | **60** | + 安全区；4 项等宽；图标 22，标签 `caption` 12 |
| 记账页键盘区 | **4 行 × 62 + 3 × 6 间距 = 266** | 单手可达；详见《05》§10 |
| 记账页操作条 | **52** | 保存按钮 |
| 抽屉抓手 | **4**（宽 36） | 顶部居中，距顶 8 |
| 模态最大高度 | 屏高 × 0.86 | 超出内部滚动 |

## 6. 栅格与断点

断点常量**只在 `breakpoints.dart`**，本文档为设计侧镜像。

| 断点 | 宽度 | 设备 | 导航 | 页面边距 | 列数 |
| --- | --- | --- | --- | --- | --- |
| `compact` | < 600 | 手机竖屏 | 底部 4 项导航 + FAB | 16 | 1 |
| `medium` | 600–839 | 手机横屏、小折叠展开 | 底部导航（横屏改左窄栏） | 24 | 1–2 |
| `expanded` | 840–1199 | 平板竖屏 | 左侧导航栏 + 内容区 | 24 | 2 |
| `large` | ≥ 1200 | 平板横屏、桌面 | 左侧导航 + 内容 + 辅助栏 | 32 | 3 |

### 6.1 各断点下的关键布局切换

| 场景 | compact | medium+ |
| --- | --- | --- |
| 首页流水 | 单列列表 | ≥ 840 时左「列表」右「当日汇总」双列 |
| 记一笔 | **形态 A**：自上而下 = 类型条 → 金额 → 键盘 → 分类宫格 → 属性栏 | **形态 B**：左「金额 + 键盘」/ 右「宫格 + 属性栏」，≥ 840 右区再分两列 |
| 报表 | 三图表纵向堆叠 | ≥ 840 双列（左折线右环形），月对比卡横排 |
| 资产 | 单列账户列表 | ≥ 840 账户卡片双列 |
| 内容最大宽度 | — | 840（超宽时居中，防止行长失控） |

**硬约束（来自 PRD STORY-1.1）**：形态 A/B 四区功能不缺失、不折叠进二级页；
**金额键盘与分类宫格必须同屏可见、无需滚动**；旋转 / 折叠**不重建页面**，草稿保留。

## 7. 对齐纪律

| 规则 | 说明 |
| --- | --- |
| **一条左线** | 同屏所有内容块的左边界共用一条线（页面边距 16 / 24 / 32）。图标与文字的视觉左边界要对齐到这条线 |
| **图标光学对齐** | 图标用内容框对齐，不用外框。24 网格图标在 20×20 内容盒内，所以图标容器比视觉尺寸小 2dp 时才对得齐 |
| **小数点成列** | 所有金额列 `text-align: end` + tabular；小数点落在同一条竖线上 |
| **基线对齐** | 图标与文字并排时对齐到**文字基线**，不是容器中线；单行行内元素用 `baseline` 对齐 |
| **数字右对齐** | 金额、计数、百分比一律右对齐；标签左对齐 |
| **不许居中的场景** | 列表行、设置项、金额。居中只用于：空态、引导页、Toast、对话框按钮组 |

## 8. 触控与命中

| 规则 | 说明 |
| --- | --- |
| 最小触控 | **44 × 44**（iOS HIG）。视觉尺寸小于此的一律用透明热区补齐 |
| 推荐高度 | 可点行优先 ≥ **48**；列表单行 60、双行 72（已含热区） |
| 命中膨胀 | 相邻元素间距 < 8 时，热区**不重叠**：按中线切分 |
| 禁止 | 缩小点击区、把热区做成不规则形状、把热区扩展到视觉元素之外 24dp 以上 |
| 键盘可达 | 所有可点元素可 Tab 聚焦，焦点环 2px `focusRing` + 2px 偏移 |

## 9. 动效几何（与《06-INTERACTION》配套）

| 令牌 | 值 | 用在哪 |
| --- | --- | --- |
| `duration.press` | **100ms** | 按压反馈（必须落在 80–120ms 区间） |
| `duration.fast` | 150ms | 开关、勾选、chip 选中、颜色过渡 |
| `duration.base` | 300ms | 页面转场、抽屉、弹窗、数字滚动 |
| `duration.slow` | 480ms | 图表入场、引导页编排 |
| `curve.out` | `cubic-bezier(.16, 1, .3, 1)` | 出场、上浮 |
| `curve.spring` | `cubic-bezier(.34, 1.56, .64, 1)` | 按压、FAB、金额反馈（**带过冲**） |
| `curve.io` | `cubic-bezier(.4, 0, .2, 1)` | 颜色、透明度对称过渡 |

位移量：弹层 `translateY 16px → 0`；Toast `translateY 12px → 0`；FAB 入场 `scale .86 → 1`。
**所有位移 ≤ 24px** —— 大位移会显廉价。
