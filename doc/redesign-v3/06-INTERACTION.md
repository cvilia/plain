## 0. 三条交互原则

1. **动效只服务可预期性**，不做装饰。任何「为了好看」的动画一律删除。
2. **动效不阻塞操作**：动效进行中，用户的新输入必须立即响应（不许排队、不许屏蔽）。
3. **任何动效可降级**：检测到 `prefers-reduced-motion` 时全部退化为纯透明度切换，时长降到 100ms。

## 1. 时长与曲线（唯一来源）

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `press` | **100ms** | 按压反馈（强制落在 80–120ms 区间） |
| `fast` | 150ms | 开关、勾选、Chip 选中、颜色过渡、指示器位移 |
| `base` | 300ms | 页面转场、抽屉、弹窗、数字滚动 |
| `slow` | 480ms | 图表入场、引导页编排 |
| `ambient` | 600ms | 无限循环类（spinner、骨架微光） |

| 曲线 | 值 | 语义 |
| --- | --- | --- |
| `out` | `cubic-bezier(0.16, 1, 0.30, 1)` | 出场 / 上浮：快起缓收 |
| `spring` | `cubic-bezier(0.34, 1.56, 0.64, 1)` | **带过冲**：按压、FAB、金额反馈 |
| `io` | `cubic-bezier(0.40, 0, 0.20, 1)` | 对称过渡：颜色、透明度、开关滑块 |

## 2. 按压反馈（每类控件的动作写死）

| 控件 | 视觉变化 | 时长 | 曲线 | 触觉 |
| --- | --- | --- | --- | --- |
| 主按钮 / 次按钮 | 底色 → `primaryPressed` / `surfaceInset`；`scale 1 → 0.97` | 100ms | spring | `lightImpact` |
| 危险按钮 | 底色 → `incomeSoft`；`scale 0.97` | 100ms | spring | `mediumImpact` |
| 文字按钮 | 底色 → `primaryTint`；`scale 0.97` | 100ms | spring | 无 |
| 列表行 | 底色 → `surfaceInset`；**不缩放** | 100ms | out | `selectionClick` |
| 设置项行 | 底色 → `surfaceInset` | 100ms | out | `selectionClick` |
| FAB | 底色 → `accentPressed`；`scale 0.94` | 100ms | spring | `mediumImpact` |
| 底部导航项 | 图标 `scale 0.93`；颜色立即变 `primaryInk` | 100ms | spring | `selectionClick` |
| 键盘键帽 | 底色 → `primaryTint`；`scale 0.96` | 100ms | spring | `lightImpact` |
| 分类图标格 | 底色 → `primaryTint`；`scale 0.96` | 100ms | spring | `lightImpact` |
| 返回键 / 图标键 | 圆形底 → `surfaceInset`；`scale 0.93` | 100ms | spring | 无 |
| 开关 | 滑块位移 + 轨道变色 | 150ms | io | `lightImpact` |
| Chip | `scale 0.96` + 底色加深 | 100ms | spring | 无 |

**统一规则**：
- 按下的**释放**（松手）用 `spring` 回弹到 1.0，**总时长 100ms**，过冲不超过 4%。
- **行类控件不缩放**（缩放会让整列表抖动，观感廉价）。行类只做叠色。
- 图标类（返回、导航、键盘）缩放幅度比按钮略大（`.93` / `.96`），因为它们体积小，需要更大比例才有反馈感。
- 所有按压反馈**即时开始**（`pointer-down`），不等 `pointer-up`。

## 3. 页面转场

| 场景 | 转场 | 时长 | 曲线 |
| --- | --- | --- | --- |
| 主从（列表 → 详情） | 详情页从右推入 100%；列表页左移 30% + `opacity .6` | 300ms | out |
| 返回 | 反向播放同一转场 | 300ms | out |
| 底部导航切换 Tab | **淡入淡出**（`opacity 0.6 → 1`，无位移） | 150ms | io |
| 进入记一笔 | **从底部上推**（`translateY 100% → 0`），因为它是「模态式」的 | 300ms | out |
| 记一笔保存后 | 停留在页内（设置项「保存后退出」默认关）；若开启退出 → 反向上推 | 300ms | out |
| 平板分栏 | 详情页推入右栏，左栏不动 | 300ms | out |
| 主题切换 | **全部颜色 150ms 过渡**（无闪屏、无重建） | 150ms | io |
| 明暗切换 | 同上，150ms | 150ms | io |

**硬约束**：
- **形态 A/B 切换（旋转、折叠）不播放转场**，直接重排（`AnimatedContainer` 级别的 300ms 布局动画可以）。
- 转场中**不重建页面**：草稿金额与已选属性必须保留（PRD AC7）。

## 4. 弹层动画

| 弹层 | 入场 | 出场 | 时长 | 曲线 |
| --- | --- | --- | --- | --- |
| 遮罩 | `opacity 0 → 1` | 反向 | 150ms | io |
| 底部抽屉 | `translateY 100% → 0` | 反向 | 300ms | out |
| 对话框 | `scale 0.94 → 1` + `opacity 0 → 1` | 反向（不位移） | 300ms | spring |
| Toast | `translateY 12px → 0` + 淡入 | 淡出 | 150ms | out |
| 下拉菜单 / 气泡 | `scale 0.96 → 1`（锚点侧为原点）+ 淡入 | 反向 | 150ms | out |
| 情绪反馈卡（V2.0） | 从 Toast 位置 `translateY 8 → 0` | 向左滑出关闭 | 300ms | out |

**抽屉可拖动关闭**：向下拖动 > 25% 高度或速度 > 800dp/s 时关闭，否则回弹（300ms `out`）。

## 5. 焦点环（键盘 / 读屏）

| 项 | 规格 |
| --- | --- |
| 出现条件 | 键盘 Tab 导航、读屏聚焦、遥控器导航；**触摸点击不出现** |
| 形态 | 2px `focusRing` 描边 + **2px 外偏移**（`outline-offset: 2px`） |
| 圆角 | 跟随控件圆角（`r2` / `r3` / `pill`） |
| 对比度 | `focusRing` 对 `surface` 与 `bg` 均 ≥ 3:1（门禁已覆盖 20 组） |
| 动画 | 出现 150ms `io`；**不淡出**（立即消失，避免残留） |
| 与按下态叠加 | 焦点环 + 按下叠色可同时出现，互不遮挡（环在外的 2px 区域） |
| 顺序 | 视觉顺序 = DOM 顺序（顶栏 → 内容 → 底栏），不跳序 |

## 6. 手势清单（有 / 无，写死）

| 手势 | 有 / 无 | 规格 |
| --- | --- | --- |
| **左右滑返回** | ✅ 有 | 屏幕左缘 24dp 起向内滑；跟手位移 + 松手按 40% 阈值判定 |
| **列表左滑删除** | ✅ 有（流水页、分类管理） | 露出 88dp 宽的删除区（`income` 底 + 白色垃圾桶）；滑过 50% 直接删除；删除后 Toast + 撤销 5 秒 |
| **列表长按** | ✅ 有（仅分类宫格） | 长按 500ms 进入排序态（`scale .96` + 抖动），拖动换位 |
| **列表长按（流水行）** | ❌ 无 | 流水行长按保留给系统（文本选择） |
| **下拉刷新** | ❌ **无** | 本地优先 App，数据永远最新；下拉不做任何事（不做「假刷新」） |
| **上拉加载更多** | ✅ 有（流水页） | 滚动到底部前 200dp 触发，加载 50 条 |
| **双指缩放** | ❌ 无 | 图表不支持缩放（改用月份切换器） |
| **双击** | ❌ 无 | — |
| **摇晃撤销** | ❌ 无 | 撤销只用 Toast 按钮 |
| **点金额揭示** | ✅ 有（遮蔽态） | 单点：点击该数字 → 临时显示 5 秒；连续点击刷新计时 |
| **抽屉下拉关闭** | ✅ 有 | 见 §4 |
| **返回键 / 手势** | ✅ 有 | 系统返回：抽屉 → 先关抽屉；键盘展开 → 先收键盘 |

## 7. 禁用反馈

| 场景 | 表现 |
| --- | --- |
| 禁用控件被点击 | **不响应、不抖动、不提示**（抖动是廉价反馈，已否决） |
| 表单必填缺失时点主按钮 | 按钮**保持可用**（不置灰），点击后：滚动到第一个缺失字段 + 2px `income` 描边 + 下方错误文案，300ms `out` |
| 金额为 0 时点分类 | 分类**只高亮不保存**（PRD AC3）；不弹任何提示 |
| 达到金额上限再输入 | 忽略该位 + 输入框水平抖动 3 次（**唯一允许抖动的场景**，因为要提示「这个按键没生效」） |
| 语义说明 | 禁用控件必须保留在可访问树里并带 `Semantics(enabled: false)` |

## 8. 成功 / 失败反馈

### 8.1 记账成功（最高频路径）

| 阶段 | 时长 | 表现 |
| --- | --- | --- |
| ① 按键 OK | 0 | 键帽按压反馈 |
| ② 金额锁定 | 150ms | 金额数字 `opacity 1 → 0.4 → 1`（**不做上移/放大**，避免跳动） |
| ③ Toast 入场 | 150ms | `已记 ¥25.00`（带「撤销」，4s） |
| ④ 金额清零 | 150ms | 清空后光标回到金额区，可连续记账 |
| ⑤ 触觉 | — | `lightImpact`；设置开启音效时播 `sfx_save` |

**连续记账（PRD AC4）**：全程停留在记账页，金额已清零，光标就位。

### 8.2 失败反馈

| 类型 | 表现 |
| --- | --- |
| 校验失败 | 字段 2px `income` 描边 + 下方 `caption`/`income` 文案；不弹对话框 |
| 操作失败（保存/备份/恢复） | Toast + `ic_status_error`，文案说明原因 + 可选「重试」；4s |
| 严重失败（数据损坏） | 对话框（非 Toast）：说明 + 两条出路（放弃 / 使用其他文件）；**不锁定、不删文件** |
| 静默失败 | 禁止。任何失败必须有可见反馈 |

### 8.3 其他状态反馈

| 状态 | 表现 |
| --- | --- |
| 离线 | 页面顶部一条 36 高的提示条（`warnSoft` 底 + `warnInk` 文字 + `ic_offline`）；恢复后 300ms 淡出。**V1.0 无网络功能，此条仅备用** |
| 预算超阈值 | 预算条变 `income` + `ic_status_warning` + 「已超支」文案（三者同时，不只靠色） |
| 长任务（备份/恢复） | 全屏进度 + 百分比 + 可取消；完成后 Toast |

## 9. 声音与触觉

| 项 | 规格 |
| --- | --- |
| 音效开关 | 设置 → 记账确认音效，**默认关**（`sound_enabled = false`） |
| 音效时机 | 仅「记账成功」一处；**不做按钮点击音、不做错误音** |
| 时长 | ≤ 400ms，音量归一化到 −14 LUFS |
| 触觉映射 | `lightImpact`：记账成功、按键、Tab 切换；`mediumImpact`：FAB、删除；`selectionClick`：列表行、开关 |
| 触觉开关 | 跟随系统（不单独提供开关）；系统「减弱触感」开启时全部禁用 |

## 10. 降级：`prefers-reduced-motion`

| 项 | 常规 | 降级后 |
| --- | --- | --- |
| 时长 | 100 / 150 / 300 / 480ms | **一律 100ms** |
| 位移 | 有（推入、上推、上浮） | **全部取消**（`translate = 0`） |
| 缩放 | 有（按压 0.97/0.93） | **取消**（`scale = 1`） |
| 保留 | — | **仅保留 `opacity` 变化** |
| 循环动画 | spinner / 骨架微光 | 保留（它们是状态指示，不是装饰），但骨架微光改为静态色块 |
| 图表入场 | 扇区依次展开 | 直接呈现终态 |

检测方式：Flutter 侧读 `MediaQuery.disableAnimations`（来自系统「减少动态效果」）；
Web 侧读 `matchMedia('(prefers-reduced-motion: reduce)')`。

## 11. 特殊场景

| 场景 | 规格 |
| --- | --- |
| **日期跨记账月** | 选择抽屉内，跨记账月的日期有 `primaryTint` 底；保存时 Toast 注明「该账单计入 8 月」（G-1 口径，不用「本月」） |
| **金额遮蔽揭示** | 单点作用域，5 秒自动重遮蔽；连续点击刷新计时不叠加（G-7） |
| **形态 A/B 切换** | 不播放转场、不重建页面；键盘与宫格必须同屏（PRD AC6/AC7） |
| **类别切换（支出→转账）** | 金额保留、分类清空、属性栏替换为转账字段；**不做整页转场**，只做 300ms 布局动画 |
| **表情反馈卡** | 出现在 Toast 之后，可左滑关闭；每周最多 3 次；超预算时**不给情绪反馈** |
| **数据刷新** | 写操作 → bump 版本 → 读侧自动重取；**不做「返回上一页手动刷新」**（工程规范） |
| **后台/前台** | 切后台**立即**打遮罩（不等 30 秒）；30 秒后回前台需解锁 |
| **Toast 与遮罩冲突** | Toast 叠在遮罩之下（`overlay` 之上只留对话框） |
