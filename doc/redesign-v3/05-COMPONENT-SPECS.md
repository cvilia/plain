| 文档属性 | 内容 |
| --- | --- |
| 文档版本 | v3.0 |
| 文档阶段 | 方案设计 · 控件解剖与状态 |

---

## 0. 通用约定

| 项 | 规则 |
| --- | --- |
| 圆角 | 只用 `r1(8) / r2(12) / r3(16) / r4(24) / pill` |
| 间距 | 只用 `s1(4)…s10(64)` |
| 描边 | 控件边界用 `lineStrong`（≥3:1）；分隔线用 `line` / `lineSoft`（不需要 3:1） |
| 阴影 | 只用 `e0…e3` |
| 触控 | 视觉 < 44 的一律用透明热区补到 **44×44**（热区不重叠，按中线切分） |
| 按压 | 统一 `scale(0.97)` + 底色叠色，**100ms** `curve.spring`；图标类 `scale(0.93)` |
| 禁用 | 底色 `disabledBg`，文字/图标 `disabledFg`；**不用 opacity** |
| 焦点 | 2px `focusRing` 描边 + 2px 偏移；只在键盘/读屏聚焦时出现 |
| 负载 | 有 `loading` 态的控件，加载中**禁用点击**但保留尺寸（不跳动） |

## 1. 主按钮 Primary Button

**用途**：一屏只有一个主操作（保存 / 确认 / 下一步）。

| 解剖 | 值 |
| --- | --- |
| 高度 | `btnLg 52`（默认）/ `btnMd 44`（次级位置） |
| 内边距 | 左右 `s5(20)`；最小宽度 **88** |
| 圆角 | `r2(12)` |
| 底色 | `primary` |
| 文字 | `labelLarge` = `heading` 15 / w600 / 色 `onPrimary` |
| 图标 | 20，色 `onPrimary`，与文字间距 `s2(8)` |
| 描边 | 无 |
| 阴影 | `e1` |
| 宽度 | 撑满内容宽（358）或按内容自适应，由 `min-width 88` 保底 |
| 触控 | = 视觉尺寸（52 ≥ 44 ✅） |

| 状态 | 背景 | 文字 | 描边 | 图标 | 动效 |
| --- | --- | --- | --- | --- | --- |
| default | `primary` | `onPrimary` | — | `onPrimary` | — |
| pressed | `primaryPressed` | `onPrimary` | — | `onPrimary` | `scale .97` 100ms spring |
| disabled | `disabledBg` | `disabledFg` | — | `disabledFg` | 无 |
| focused | `primary` | `onPrimary` | `focusRing` 2px + 2px offset | 同 | 150ms |
| loading | `primary` | 隐藏文字？**不隐藏** | — | 换成 `ic_loading` 旋转 | spinner 600ms 线性无限 |
| error | 不适用（错误用 Toast 表达） | | | | |

**文案位**：`保存` / `Save`；最长 `Create backup`（108dp）→ 按钮 `flex` 撑开，单行不换行。
**亮/暗**：`primary` 与 `onPrimary` 在 20 组中已全部 ≥ 4.5:1（门禁覆盖）。

## 5. 列表行 List Row（本系统最重要的控件）

**没有卡片、没有底色、没有圆角。** 行与行之间只有一条 `lineSoft`。

| 解剖 | 单行 | 双行 |
| --- | --- | --- |
| 高度 | **60** | **72** |
| 左右内边距 | `s4(16)`（在分组面板内则 0，由面板给） | 同 |
| 上下内边距 | `s2(8)` | `s3(12)` |
| 左槽宽度 | **44**（图标 24 + 分类圆点 6 + 间距） | 44 |
| 分类圆点 | **Ø6**，`categoryColor[iconRef]`，垂直居中，距行左边缘 16 | 同 |
| 图标 | 24，`ink2`，与圆点二选一（分类行用圆点+图标？**不** —— 见下） | |
| 主文 | `heading` 15 / w500 / `ink`，单行 `ellipsis` | 同 |
| 副文 | `caption` 12 / w500 / `muted`，单行 `ellipsis`，与主文间距 `s1(4)` | 同 |
| 右侧金额 | `amount-s` 15 / w600 / 支出 `ink`、收入 `income`，右对齐 | 同 |
| 右侧箭头 | `ic_chevron_right` 20 / `faint` | 同 |
| 分隔线 | `lineSoft` 1px，**左缩进 16**（不从最左边起，形成「挂线」节奏） | 同 |

**分类行的左槽规则（关键设计决定）**：
分类行左槽**不放大圆底图标**（那是上一版的贴纸感来源）。改为 **24px 单色图标 + 图标底部 6px 分类色圆点**
或 **纯 6px 圆点 + 主文**（紧凑模式）。§8 有明确二选一：**流水列表用「单色图标 + 无圆点」，分类统计列表用「6px 圆点 + 无图标」** —— 同屏不混用。

| 状态 | 背景 | 说明 |
| --- | --- | --- |
| default | transparent | — |
| pressed | `surfaceInset` | 100ms，`scale 1`（**行不缩放**，只叠色 —— 行缩放会让整列表抖） |
| selected | `primaryTint` | 多选模式 |
| disabled | transparent + 文字 `disabledFg` | — |
| focused | transparent + `focusRing` 内描边 | 键盘导航 |
| swipe-revealed | 右滑露出删除底（`income` 底，白字） | 见《06》§6 |

**文案位**：分类名 ≤ 6 字；英文最长 `Entertainment`（13 字符 ≈ 88dp）→ 主文列可用宽 = 358 − 44 − 金额宽(≈90) − 16 = 208dp ✅。

## 10. 数字键盘 Numeric Keypad（记一笔的核心）

**上一版最大缺陷之一：数字漂在空白上。v3 给每个数字一个键帽。**

| 解剖 | 值 |
| --- | --- |
| 布局 | **4 列 × 4 行** |
| 键帽 | **62 × 62**，圆角 `r2(12)` |
| 键距 | `keypadGap 6` |
| 键帽底色 | `surface2` |
| 键帽描边 | 1px `line` |
| 键帽阴影 | `e1`（让「键」有厚度，这是键帽感的来源） |
| 数字字号 | `amount-l` 22 / w500 / `ink` |
| 图标键 | ⌫ `ic_back` 24 / `ink2`；C `ic_close` 20 / `ink2` |
| OK 键 | 跨 2 列宽（2×62+6 = 130），高 62，圆角 `r2(12)`，底 `accent`，文字 `onAccent` / `heading` 15 / w600 |
| 分区 | 数字区（列 1–3）与操作区（列 4）之间加 **12dp 沟槽**（`s3`），不用线 —— 用留白分区比用线安静 |
| 键位 | 行1 `1 2 3 ⌫` / 行2 `4 5 6 C` / 行3 `7 8 9 (空)` / 行4 `. 0 OK(跨列3-4)` |
| 总高 | 4 × 62 + 3 × 6 = **266** |
| 触控 | 62 ✅ 且 **全部落在拇指可达区**（屏高 844 − 状态栏 47 − 顶栏 56 − 金额区 120 − 键盘 266 − 安全区 34 = 321 的余量给分类宫格） |

| 状态 | 键帽 | 数字 | 动效 |
| --- | --- | --- | --- |
| default | `surface2` / `line` | `ink` | — |
| pressed | `primaryTint` | `ink` | `scale .96` **100ms**（键帽要「沉下去」） |
| disabled | `disabledBg` / `line` | `disabledFg` | — |
| held（长按退格） | `primaryTint` + 键帽边框加粗到 1.5 | `ink` | 500ms 后开始连删，每 60ms 一次 |
| 焦点 | `surface2` + `focusRing` | `ink` | 150ms |

**键盘约束（来自 PRD）**：只有数字 `0–9`、小数点 `.`、退格 `⌫`、清空 `C`、确认 `OK`。
**没有四则运算、没有等号** —— 键帽上不得出现 `+ − × ÷ =`。

## 13. Segment / Tab

两种形态，用途不同：

| | Segmented（分段控件） | Tab（页签） |
| --- | --- | --- |
| 用途 | 同层级 2–4 个互斥视图（资产页：概览/账户/持仓） | 内容分类切换 |
| 高度 | **36**（轨道 36，滑块 32） | **44** |
| 圆角 | 轨道 `r2(12)`，滑块 `r1(8)` | 无 |
| 底色 | 轨道 `surfaceInset` | `appBg` |
| 选中 | 滑块 `surface` + `e1` + 文字 `ink` w600 | 文字 `ink` w600 + **下方 2px `primaryInk` 下划线** |
| 未选中 | 文字 `muted` w500 | 文字 `muted` w500 |
| 指示器动画 | 滑块 `translateX`，**150ms** `curve.out` | 下划线 `translateX` + 宽度，150ms |
| 触控 | ≥44（轨道 36 + 上下各 4 热区） | 44 ✅ |

**英文超长的硬案例**：记账页类型条 5 项（`Expense / Income / Transfer / Lend / Borrow`）在 358dp 内放不下
→ **英文下改为横向滚动 Tab**，`Transfer` 必须完整显示，不省略、不缩到 12px 以下。
