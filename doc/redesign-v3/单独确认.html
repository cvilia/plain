自动规则

规则 = 条件（IF） + 动作（THEN）。一条账单可在保存时命中多条规则， 按优先级顺序执行，后者可覆盖前者。 每次命中都会记入「规则执行日志」，可查看、可撤销。
规则 · 5 条
1星巴克自动归类IF　商户 包含 星巴克THEN　分类 → 餐饮 · 饮料　账户 → 招行信用卡已命中 12 次
2地铁通勤归类IF　商户 包含 地铁 且 金额 ≤ 20THEN　分类 → 交通 · 公交地铁已命中 34 次
3大额支出标记IF　金额 ≥ 500THEN　打标签 #大额　备注追加提醒已命中 6 次
4工资自动入账IF　金额 = 15,000 且 类型 收入THEN　分类 → 其他 · 工资　账户 → 招行储蓄已命中 1 次
5晚间消费提醒IF　时间 在 23:00–05:00THEN　打标签 #深夜（仅标记不通知）已命中 3 次
执行阶段：保存前（可改写分类 / 账户） / 保存后（只做标记与通知）。 改动仅作用于规则生效之后的新账单，不回改历史。

桌面端与多端

Flutter 工程结构已含 macos / web / windows 目录 —— 四端不是「将来重做」，而是「逐步点亮」。 这决定了桌面端的边际成本远低于重写。
四端能力矩阵
手机（iOS / Android）3 秒记账 · 点分类即保存已支持
平板（iPad / Android Pad）双栏布局 · 侧栏常驻 · 手写备注已支持
桌面（Windows / macOS）全键盘操作 · 批量录入 · 报表打印V3.0
Web（浏览器）免安装查看与导出 · 只读为主V3.0
桌面端差异化能力（V3.0）
全键盘录账（Tab 跳转 / Enter 保存）规划
CSV / Excel 批量导入与去重规划
报表导出 PDF 并打印规划
多账本同开（侧栏切换）规划
桌面端与 Web 端的先后顺序是开放问题：Web 先行可以覆盖「临时在别人电脑上查账」， macOS 先行则贴近重度用户。 建议在 V2.0 云同步落地后按真实用量决定。
