## 1. 这份清单管什么

管**非业务的地基能力**——日志、埋点、错误处理、存储、平台桥接、设计系统、工程流水线。它们的共同特征是：**不产出用户可见的功能，但决定业务功能的开发效率与后期返工量**。

判断优先级只看一个维度——**后补代价**：

| 后补代价 | 含义 | 举例 |
|---|---|---|
| 高 | 能力缺失时，业务代码会各自造轮子；补齐需改动大面积既有代码 | 日志、埋点、金额值对象、时间注入、Design Token、错误模型 |
| 中 | 可在局部补齐，影响有限 | 埋点数量、主题切换、断点工具 |
| 低 | 纯新增，不动存量 | 诊断包导出、深层设置项 |

**结论先行**：标「高」且属 V1.0 范围的能力，必须在业务功能开发之前或与之并行完成，不能等到功能做完再回头补。

### 3.1 A1 与 A3 的两条设计红线

**日志与埋点必须由 API 设计保证合规，而不是靠开发者自觉。** 具体做法：

1. **只接受结构化字段，不开放「任意字符串」入参**。日志门面提供 `log.entryCreated(source: …, amountCents: null)` 这类语义方法，**不提供** `log.info('记了一笔 ¥25 餐饮')` 这种自由文本入口。自由文本入口一旦存在，金额和备注明文就会不可避免地流进日志文件。
2. **金额、备注、账户名一律不入日志**。需要定位问题时用 ID 与哈希。这条不是洁癖——备份与诊断包会离开设备（用户分享给客服），明文金额就是数据泄露。

**埋点事件字典**：埋点事件与字段必须先在文档中登记（PRD §9 已定义 6 个核心事件），代码侧由枚举 + 生成代码约束，**禁止随手新增字符串事件**。未登记的事件类型在构建期即报错。理由：埋点一旦散落成字符串，三个月后就没人知道哪些字段还能改。

### 6.1 D6 值得单独说

记账产品的时间处理不是「调个 `DateTime.now()`」那么简单，它同时被四件事约束：报表月边界（月起始日可自定义，PRD STORY-5.1）、周期记账的锚定日与短月顺延（V2.0）、备份文件的时间戳与版本、跨时区用户的「今天」。这些逻辑如果各自实现，会得到互相矛盾的结果。

**做法**：domain 层提供唯一的时间语义入口（如 `AccountingCalendar`），所有「某笔账单属于哪个月」「今天是几号」的判断都必须经过它。配合《05》B2（禁止裸 `DateTime.now()`），这两条一起才能保证时间是可测试、可推理的。

## 11. 排期建议：三个波次

**Wave 0（与项目脚手架同步，业务开发前必须就绪）**——这 9 项缺失时，业务代码会立刻开始各自造轮子：

F5 静态守卫 → F2 构建 flavor → F1 测试基建 → A1 日志 → A2 崩溃捕获 → A6 全局错误 UI → E1 Design Token → B1 启动编排 → C5 数据库连接

**Wave 1（与业务功能并行，V1.0 中段完成）**：

C1 偏好设置 → C2 密钥管理 → C3 change_log 写入器 → B2 生命周期 → D6 时区日期 → D7 货币格式化 → E4 组件库 → E6 ChartKit → A3 埋点 → A4 性能监控

**Wave 2（V1.0 收尾与提测前）**：

C4 备份恢复 → B4 迁移执行器（含迁移前备份）→ D1 深链路由 → D2 小组件桥 → D3 应用锁 → D4 权限时机 → D5 分享导出 → E3 断点工具 → E5 图标系统 → E7 无障碍 → A5 诊断包 → G1/G2 合规与素材 → F4 版本对齐 → F3 CI 全量门禁

**说明**：C3（change_log）放在 Wave 1 而非 Wave 0，因为它只被数据层引用，早建晚建不影响业务代码形态；但必须**先于任何写事务落地**，所以不能拖到 Wave 2。

### 11.1 Wave 0 必须显式占位（不得留作「顺便做」）

Wave 0 的 9 项没有任何用户可见产出，是排期中最先被压缩的对象。**处理方式：在开发计划里为它们单独立一个里程碑（`M0 地基`），拥有独立工期与独立退出标准，不并入任何功能迭代。**

| 占位方式 | 内容 |
|---|---|
| 独立里程碑 | `M0 地基`，排在首个功能迭代之前，不可与其他里程碑并行挤压 |
| 独立工期 | 见下表，按「1 名熟练 Flutter 开发」口径估算，**仅为占位量级** |
| 独立退出标准 | 9 项全部通过，且逐项可机器判定（见下表） |
| 独立看板泳道 | 任务看板上单独成列，不允许被功能任务挤占 |
| 交付物 | 一个可运行的空壳工程：能编译、能启动、能连库、CI 全绿，且 9 项各有冒烟用例 |
