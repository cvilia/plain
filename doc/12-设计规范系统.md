## 1. 结论先行

**设计规范系统 = 一套令牌（48 个）× 十个皮肤（10 主题 × 亮暗 = 20 组合）× 一套组件（9 个）× 一套门禁（820 项对比度）。**

| 层 | 数量 | 唯一事实来源 | 本文章节 |
| --- | --- | --- | --- |
| 设计令牌 | 48 字段 | `lib/app/theme/tokens.dart` | §3 |
| 主题皮肤 | 10 套 × 2 态 | `lib/app/theme/theme_registry.dart` | §4 |
| 语义色板 | 9 键 × 2 态 | `theme_registry.dart` `_semLight` / `_semDark` | §5.1 |
| 分类色板 | 12 色（跨主题恒等） | `theme_registry.dart` `categoryColorMap` | §5.2 |
| 排版尺度 | 13 级 | `theme_resolver.dart` `textTheme` | §6 |
| 空间与形态 | 圆角 3 档 / 阴影 3 档 / 间距 4 基数 | `theme_resolver.dart` + 组件实况 | §7 |
| 动效 | 3 时长 × 3 曲线 | `theme_resolver.dart` alpha 与《09》曲线 | §8 |
| 组件 | 9 个 | `lib/design_system/*.dart` | §9 |
| 布局断点 | 3 档 | `lib/app/breakpoints.dart`（见《07》） | §10 |
| 无障碍门禁 | 820 + 1 项 | `tool/theme_contrast_check.dart` | §11 |

**三条铁律**（改任何一处都要回头看这三条）：

1. **令牌是唯一取色入口**。任何界面不得裸写十六进制；颜色只能来自 `AppTokens` 字段或 `BrandColors` 门面。
2. **主题只换品牌层**。换皮肤时，中性层按 tone 走、品牌层按 spec 走、语义色与分类色**恒等不变**（INV-1）。
3. **改色必须跑门禁**。任何色值改动后必须 `dart run tool\theme_contrast_check.dart` 全绿，820 项一项不能红。

## 2. 设计原则

| 原则 | 含义 | 落点 |
| --- | --- | --- |
| **纸张感** | 界面像一张安静的书页，不是仪表盘。大面积留白，低饱和，无重投影。 | `surface` 用纯白/近白，阴影只用 `shadow1~3` 三档且极淡 |
| **数字优先** | 金额是主角，其余都是配角。金额字号最高、字重最重、字距略松。 | §6 排版尺度 `amountXL ~ amountS` |
| **冷底暖点** | 冷色铺面（品牌主色 + 中性层），暖色只在关键动作上出现（accent）。 | `primary` 铺面 / `accent` 仅用于 FAB、保存、收入强调 |
| **色彩即语义** | 红=进账（中文习惯），绿=下跌/节省；语义色跨主题恒等，不给皮肤留自由度。 | §5.1，INV-1 |
| **三层雾面** | 页面底 → 屏幕底 → 卡面，三级明度递进，靠明度而非描边分层。 | `bg` → `appBg` → `surface` / `surface2` |
| **克制动效** | 动效只服务「可预期性」，不做装饰。时长 170 / 340ms 两档为主。 | §8 |
| **可读即合规** | 正文 ≥ 4.5:1，大字 ≥ 3:1，图形 ≥ 3:1；彩色小字必须过 `inkForLayers` 多宿主校验。 | §11 |

## 3. 设计令牌（48 字段）

**唯一事实来源：`plain/lib/app/theme/tokens.dart`。** 字段名 1:1 映射 CSS 变量（kebab-case → camelCase），规格见《04》§16.1。

### 3.1 令牌分组

| 组 | 字段数 | 字段名 | 说明 |
| --- | --- | --- | --- |
| **Neutral** | 10 | `bg` `appBg` `surface` `surface2` `ink` `ink2` `muted` `faint` `line` `lineSoft` | 中性层，随 tone + 明暗变化 |
| **Brand primary** | 4 | `primary` `primaryDeep` `primarySoft` `primaryTint` | 品牌主色，随皮肤变化 |
| **Brand accent** | 4 | `accent` `accentDeep` `accentSoft` `accentGrad` | 品牌强调色（`accentGrad` 是渐变对象） |
| **Derived** | 4 | `onPrimary` `onAccent` `primaryInk` `accentInk` | 派生色：主/强调色作底时的前景色与文字态 |
| **Income** | 4 | `income` `incomeSoft` `incomeLine` `incomeInk` | 收入语义（红），跨主题恒等 |
| **Status** | 6 | `okSoft` `okInk` `warnSoft` `warnInk` `dnBg` `dnInk` | 状态语义，跨主题恒等 |
| **Atmosphere** | 5 | `heroGrad0` `heroGrad1` `heroDarkGrad0` `heroDarkGrad1` `frame` | 渐变端点与机身框 |
| **Charts** | 3 | `chartTrack` `barFill` `dash` | 图表轨道/柱/虚线，由主色与底派生 |
| **Glow / Shadow** | 8 | `glowPrimary` `glowAccent` `shadowPrimary` `shadowAccent` `toastBg` `shadow1` `shadow2` `shadow3` | 氛围光、品牌投影、toast 底、三级阴影 |
| **合计** | **48** | | |

### 3.2 令牌命名与映射规则

| 规则 | 说明 |
| --- | --- |
| CSS 变量名 | kebab-case，如 `--primary-deep`、`--ink-2`、`--app-bg` |
| Dart 字段名 | camelCase，如 `primaryDeep`、`ink2`、`appBg` |
| 数字后缀 | `ink2` ↔ `--ink-2`；`surface2` ↔ `--surface-2`；无连字符者直接对应 |
| 渐变字段 | `accentGrad` / `heroGrad0/1` / `heroDarkGrad0/1` 在 CSS 侧是 `linear-gradient(...)`，在 Dart 侧是 `LinearGradient` 或端点色 |

### 3.3 令牌的「三个来源」

同一个令牌，值从哪来决定了它能不能被皮肤改：

| 来源 | 令牌 | 换皮肤时 | 换明暗时 |
| --- | --- | --- | --- |
| **中性层**（按 tone） | Neutral 10 项 | **不变**（同 tone 主题共用） | 变（亮/暗两套） |
| **品牌层**（按 spec） | primary / accent 8 项 + Atmosphere 5 项 | **变** | 变（light / dark 两套） |
| **派生层**（运行时算） | Derived 4 / Income 4 / Status 6 / Charts 3 / Glow-Shadow 8 | 部分变 | 变 |
| **恒等层**（INV-1） | 语义色（income / ok / warn / dn）+ 分类色 12 | **恒等** | 变（明暗） |

⚠️ **`primarySoft` / `primaryTint` / `accentSoft` 不是独立色值**，而是「品牌色 × 全局 alpha」的透明层（见 §4.3 透明度政策）。它们在 Flutter 侧保持半透明，由绘制时与宿主底合成，因此同一令牌在不同宿主上观感略有差异——这是设计意图（空灵感），不是缺陷。

### 3.4 色值字节序（易错点）

| 环境 | 格式 | 示例（青瓷主色） |
| --- | --- | --- |
| CSS | `#RRGGBBAA`（字母序：红绿蓝透明） | `#14B8A6` |
| Dart | `0xAARRGGBB`（透明红绿蓝） | `0xFF14B8A6` |

**两者相反。** Dart 侧禁止手拼字节，一律用 `Color.fromRGBO(r, g, b, alpha)` 或直接写 `0xAARRGGBB` 字面量。

### 4.2 中性层：3 个 tone × 2 明暗

中性层**不随皮肤变，只随 tone 变**。三档 tone：`cool`（冷调，7 套主题用）/ `warm`（暖调，杏黄、豆绿用）/ `neutral`（中性，素白用）。

| tone | 亮态 `bg` | 亮态 `ink` | 暗态 `bg` | 暗态 `ink` |
| --- | --- | --- | --- | --- |
| cool | `#F1F5F3` | `#1F2D28` | `#141A18` | `#E4EBE6` |
| warm | `#F6F1E8` | `#241F18` | `#191612` | `#EDE7DA` |
| neutral | `#F3F3F1` | `#1C1C1B` | `#1B1B1A` | `#E9E9E6` |

**三层雾面递进（亮态 cool）**：`bg #F1F5F3` → `appBg #F8FAF9` → `surface #FFFFFF` / `surface2 #FAFCFB`。靠明度差分层，不靠描边。

**暗态明度反转**：`bg` 最深（`#141A18`）→ `appBg`（`#222C29`）→ `surface`（`#2B3733`）→ `surface2`（`#323F3A`）逐级提亮。**暗态不是亮态取反**，而是独立设计的一套，保证层级关系与亮态一致。

### 4.3 透明度政策（全局常量，不随主题）

| 层 | 亮态 alpha | 暗态 alpha | 说明 |
| --- | --- | --- | --- |
| `primarySoft`（soft） | **0.16** | **0.26** | 品牌淡彩层 |
| `primaryTint`（tint） | **0.10** | **0.16** | 更淡的品牌染色层 |
| `accentSoft`（aSoft） | **0.16** | **0.26** | 强调淡化层 |

**暗态 alpha 更高是刻意的**：同样的 alpha 在深底上会「看不见」，故暗态提到 26% / 16%。

**结构色必须不透明**：`surface` / `bg` / `line` / `ink` 等结构色一律不透明；只有品牌淡彩层（primarySoft / primaryTint / accentSoft）用 alpha。语义淡彩层（`incomeSoft` / `okSoft` / `warnSoft` / `dnBg`）**保持不透明**。

### 4.4 亮暗两态

| 项 | 规则 |
| --- | --- |
| 解析入口 | `resolveBrightness(ThemeMode, platformBrightness)`，支持 `system` / `light` / `dark` |
| 组合数 | 10 主题 × 2 明暗 = **20 组合** |
| 缓存 | `themeDataFor(id, brightness)` 走 20 条缓存，**构建一次后复用** |
| 禁令 | 禁 `ColorScheme.fromSeed`；禁在 `build()` 内计算颜色；`ThemeData` 必须走缓存 |

### 4.5 派生色算法（4 项）

派生色不是写死的，是运行时按对比度算出来的（`color_math.dart`）：

| 令牌 | 算法 | 门槛 |
| --- | --- | --- |
| `onPrimary` | `pickOn(primary, tone.ink, 4.5)` —— 在主色上取黑或白字 | ≥ 4.5:1 |
| `onAccent` | `pickOn(accent, tone.ink, 4.5)` | ≥ 4.5:1 |
| `primaryInk` | `inkForLayers(primary, [softOver×4, surface, bg], 4.5)` —— 与主色同色相的「文字态」 | ≥ 4.5:1 **对全部宿主** |
| `accentInk` | `inkForLayers(accent, [aSoftOver, surface, bg], 4.5)` | ≥ 4.5:1 **对全部宿主** |

**`inkForLayers` 的意义**：彩色小字可能落在卡面、页面底、淡彩层等多种宿主上，必须保证**在每一种宿主上都过 4.5:1**，而不是只在一种上过。这是本系统与常见设计的最大差异点。

### 4.6 其余派生项

| 令牌 | 算法 |
| --- | --- |
| `heroGrad0/1` | 经 `heroSafe()` 保底（保证白字可读），再取 `brand.hero0/1` |
| `heroDarkGrad0/1` | 设计锁死白字，`heroSafe()` 作安全网 |
| `chartTrack` | `chartTrack(surface2, primary, isDark)` —— 主色与次级面混合 |
| `barFill` | `barFill(appBg, primary, isDark)` |
| `dash` | `dashColor(line, muted)` |
| `glowPrimary/Accent` | 品牌色 + alpha（亮 0.08 / 暗 0.12） |
| `shadowPrimary/Accent` | 品牌色 + alpha（亮 0.10 / 暗 0.18） |
| `toastBg` | 直接取 `tone.ink`（**反向墨色**，不写死 hex） |
| `shadow1/2/3` | 黑色 + alpha（亮 0.06 / 0.10 / 0.14；暗 0.20 / 0.28 / 0.36） |
| `accentGrad` | `linearGradient(accentSheen(accent, onAccent), accent)` —— 135° 斜向高光渐变 |

### 5.3 色彩用法约束

| 约束 | 说明 |
| --- | --- |
| 主色（`primary`） | 只用于：主按钮底、FAB、选中态、进度、图表主系列、链接文字（用 `primaryInk`） |
| 强调色（`accent`） | 只用于**关键动作**：FAB 高亮、保存按钮、收入强调、hero 渐变点缀。**不得大面积铺** |
| 收入红（`income`） | 仅用于收入金额、收入 chip 的文字与底色 |
| 下跌绿（`dn*`） | 仅用于环比下跌、节省、达成目标的正面反馈 |
| 分类色 | 仅用于环形图扇区、分类图标圆底、分类圆点。**不得用于按钮或文字** |
| 中性墨（`ink`） | 正文与标题一律用中性墨，**不用纯黑 `#000`**（压纯白禁令） |

## 6. 字体与排版

### 6.1 字体族（3 套）

| CSS 变量 | 用途 | 字体栈 |
| --- | --- | --- |
| `--font-display` | 标题/氛围文字 | `LXGW WenKai Screen` → `KaiTi` → `STKaiti` → `SimKai` → serif |
| `--font-body` | 正文（默认） | `PingFang SC` → `HarmonyOS Sans SC` → `MiSans` → `Source Han Sans SC` → `Microsoft YaHei` → sans-serif |
| `--font-num` | 金额与数字 | `Quicksand` → `PingFang SC` → `Microsoft YaHei` → sans-serif |

**约束**：字体必须**免费可商用 + 本地下载**，**禁用 CDN**。系统字体栈作兜底（界面渲染用系统中文字体无授权问题）；但**图标/Logo/字标等「素材化」使用**受系统字体 EULA 限制，须用开源字体（见《11》）。

### 6.2 排版尺度（13 级）

**唯一事实来源：`theme_resolver.dart` `textTheme`**（Material 命名）+ 金额专用扩展。

> **与《07》`AdaptiveFontSizes` 的关系（两套并存，勿混用）**：本节是**设计令牌字阶**（全端固定，与 `textTheme` 一一对应）。另有断点自适应字号工具 `AdaptiveFontSizes`（`lib/app/breakpoints.dart`，见《07》§4 L4）：`display` 记账页大金额 **48 / 56 / 64**（随断点变）、`body` 15 / `title` 17 / `caption` 12（部分自适应页面使用）。**记账页输入金额走 `AdaptiveFontSizes.display`，不是 `amountL`**。

| 语义名 | 字号 | 字重 | 颜色令牌 | 用途 |
| --- | --- | --- | --- | --- |
| `amountXL` | **40** | w700 | `ink` | Hero 大额（账单详情 `entry_detail_page`） |
| `amountL` | **32** | w700 | `ink` | 卡片主数字、账户合计（`accounts_page`） |
| `amountM` | **22** | w600 | `ink` | 卡片主数字、报表结余 |
| `amountS` | **16** | w600 | `ink` | 列表行金额 |

| --- | --- | --- |

| 令牌 | 亮态 | 暗态 | 用途 |
| --- | --- | --- | --- |

## 8. 动效规范

### 8.1 时长与曲线

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `dur-fast` | **170ms** | 微交互：按下、开关、chip 选中、颜色过渡 |
| `dur-base` | **340ms** | 主过渡：页面切换、抽屉、弹窗、数字滚动 |
| `dur-slow` | 520ms | 大动效：引导页编排、图表入场 |
| `ease-out` | `cubic-bezier(0.16, 1, 0.3, 1)` | 默认曲线（强出缓入，收尾快） |
| `ease-spring` | `cubic-bezier(0.34, 1.56, 0.64, 1)` | 弹性曲线（弹窗、FAB、金额反馈） |
| `ease-in-out` | `cubic-bezier(0.4, 0, 0.2, 1)` | 对称过渡（颜色、透明度） |

### 8.2 动效清单

| 场景 | 规范 |
| --- | --- |
| **涟漪（Ripple）** | 所有可点元素；水波色 = 主色 12% alpha；半径随元素尺寸，时长 340ms |
| **按钮按压** | `scale 1 → 0.97`，`dur-fast` + `ease-spring` |
| **FAB** | 入场 `scale 0.8 → 1 + 位移 12px`，`ease-spring`；点击 `scale → 0.94 → 1` |
| **弹窗/抽屉** | 遮罩淡入 170ms；内容 `translateY 24px → 0` + `opacity`，340ms `ease-spring` |
| **金额清零** | 记账保存后金额数字 `opacity 1 → 0` + 轻微上移，170ms；再复位 |
| **数字滚动** | 金额变化时逐位滚动（`Timer` 分帧），总时长 ≤ 340ms |
| **页面切换** | 左右滑动 340ms `ease-out`；Tab 切换用淡入淡出 170ms |
| **图表入场** | 环形图扇区从 12 点钟起按序展开（每扇区 +40ms，总 ≤ 520ms）；折线从左到右绘制 |
| **Toast** | 入 `translateY 16px → 0` + 淡入，170ms；停留 1500ms；出淡出 170ms |
| **骨架屏** | 微光扫过，1.4s 循环（仅首帧 > 200ms 时启用） |

### 8.3 无障碍与降级

| 规则 | 说明 |
| --- | --- |
| `prefers-reduced-motion` | **必须尊重**：检测到后，所有位移/缩放动效降为**纯透明度切换**，时长降到 100ms |
| 动效不得阻塞操作 | 任何动效期间用户的新输入必须立即响应 |
| 无闪烁 | 禁止 3Hz 以上的闪烁；亮度跳变幅度 ≤ 30% |
| 焦点可见 | 键盘/读屏焦点必须有可见描边（2px `primary` + 2px 偏移） |

## 11. 无障碍与对比度门禁

### 11.1 门禁规模

**`tool/theme_contrast_check.dart` = 41 项检查 × 20 组合 = 820 项 + 1 项 INV-1 不变量。**

| 项 | 说明 |
| --- | --- |
| 组合数 | 10 主题 × 2 明暗 = **20** |
| 每组合检查项 | **41** 项（正文、标题、按钮、chip、图标、图表、语义色、派生色等） |
| 总计 | **820 项**，须全绿 |
| INV-1 | 1 项：语义色与分类色跨主题恒等 |

**运行方式**：`dart run tool\theme_contrast_check.dart`（用户自行运行；助手不跑构建）。

### 11.2 对比度阈值

| 元素类型 | 阈值 | 依据 |
| --- | --- | --- |
| 正文文字（< 18px） | **≥ 4.5:1** | WCAG 2.1 AA |
| 大字（≥ 18px 或 ≥ 14px 粗体） | ≥ 3:1 | WCAG 2.1 AA |
| 图形与 UI 组件边界 | ≥ 3:1 | WCAG 2.1 AA（1.4.11） |
| 彩色小字（primaryInk / accentInk / incomeInk） | **≥ 4.5:1 对全部宿主** | 本项目加严 |
| 焦点指示器 | ≥ 3:1 | WCAG 2.1 AA |

### 11.3 其他无障碍要求

| 要求 | 说明 |
| --- | --- |
| 触控目标 | ≥ 44×44（iOS）/ 48×48（Android） |
| 文本缩放 | 支持系统字号放大至 **200%** 不截断关键信息 |
| 读屏支持 | 所有交互元素有语义标签；金额读作「二十五元」而非「二五」 |
| 色盲友好 | 收入/支出不只靠颜色区分，**必须另有符号或文字**（如 `+` / `-`） |
| 动效降级 | 尊重 `prefers-reduced-motion`（§8.3） |
| 遮蔽可及 | 遮蔽态必须能通过点击揭示，不能永久锁死 |

### 11.4 门禁触发的改色流程

1. 改色前：确认改的是**品牌层**（可改）还是**恒等层**（改即违反 INV-1）。
2. 改色后：跑 `theme_contrast_check.dart`，逐项看红。
3. 若红：优先调「文字色」而非「底色」（底色动一发牵全身）。
4. 全绿后：同步回写 `theme_registry.dart` 与本文 §4.1 / §5 表格。
5. **每次改色必须同时更新**：`theme_registry.dart` + 《04》§16.1 + 本文 + 《09》高保真 UI 的 CSS 变量块。四处同源。

### 12.4 常见反例

| 反例 | 为什么错 | 正确做法 |
| --- | --- | --- |
| 在 widget 里写 `Color(0xFF123456)` | 绕过令牌，换皮肤失效 | 用 `tokens.primary` |
| 用 `ColorScheme.fromSeed` | 生成色不受控，门禁失效 | 显式构造 `ColorScheme` |
| 在 `build()` 里算颜色 | 每帧重算，性能与一致性双输 | 走 `themeDataFor` 20 条缓存 |
| 把分类色写进主题 spec | 违反 INV-1，图表配色随皮肤漂移 | 用 `categoryColorMap` |
| 用绿色表示支出减少 | 与「红涨绿跌」冲突 | 支出用 `ink`，下跌才用 `dn*` |
| 卡片用 Material elevation | 观感与「纸张感」冲突 | `elevation: 0` + 描边 + `shadow1` |
| 暗态直接给亮态色值取反 | 层级关系错乱 | 用独立的暗态调色板 |
| 彩色小字只在卡面上验证 | 其他宿主上可能不达标 | 用 `inkForLayers` 多宿主校验 |

## 13. 关键决策记录

| # | 决策 | 理由 | 放弃的方案 |
| --- | --- | --- | --- |
| 1 | 令牌用**不可变值对象**（48 字段）而非 CSS 变量运行时读 | Flutter 侧编译期常量、可缓存、类型安全 | 运行时 Map 查表（丢类型、易拼错键） |
| 2 | 语义色与分类色**跨主题恒等** | 用户换皮肤不该改变「红=收入」的认知 | 每主题一套语义色（认知负担、图例混乱） |
| 3 | soft/tint 层用**半透明**而非混合色值 | 同一令牌在不同宿主上自然融合，减少令牌数 | 预计算每个宿主上的混合色（组合爆炸） |
| 4 | 彩色小字必须**对全部宿主**过 4.5:1 | 彩色字可能落在多种底上，单点校验不可靠 | 只对主面校验（换布局即可能失守） |
| 5 | 暗态 alpha **高于**亮态 | 同 alpha 在深底上不可见 | 亮暗共用 alpha |
| 6 | 记账页**形态 A/B 共享组件与状态** | 旋转/折叠不重建页面，草稿不丢 | 两套独立实现（状态易漂移） |
| 7 | 日历**自研**而非系统日期选择器 | 需表达记账月边界、风格统一、跨端一致 | 系统 `showDatePicker`（风格割裂、无法标注记账月） |
| 8 | 金额小数位**字号降级**（0.65×） | 整数部分是主角，视觉重量分级 | 全等大（数字显得笨重） |
| 9 | 卡片走**描边 + 极淡阴影** | 「纸张感」定位，不用浮起板 | Material elevation（与定位冲突） |
| 10 | 门禁 820 项**纳入 CI**（待强化项） | 改色不跑门禁是最大回归来源 | 人工目测（不可靠） |
