## 4. `lib/` 分层总览

```text
lib/
├── main.dart                  # 入口（193 行）
├── app/                       # 应用壳（19 文件 / 2,810 行）
├── core/                      # 与业务无关的通用能力（12 文件 / 1,300 行）
├── domain/                    # 领域层（无 Flutter 依赖，34 文件 / 4,579 行）
├── data/                      # 基础设施与持久化（19 文件 / 3,569 行）
├── design_system/             # 跨页面复用 UI 组件（16 文件 / 3,059 行）
└── features/                  # 功能模块（按业务切，46 文件 / 19,316 行）
```

**依赖方向**（《05》A 组架构守卫）：

```text
domain  ←  data  ←  features
   ↑         ↑          ↑
   └── core ─┴──────────┘
design_system（仅依赖 core + app/theme）
app（壳，可依赖全部）
```

- `domain/**`、`core/money/**` **禁** `package:flutter`（《05》A1）
- `features/<A>` 不得 import `features/<B>`（A2）
- `features/**/presentation` 不得 import `data/**`（A3）
- SQL 写路径只在 `data/repositories/**`（A4，当前有 **8 处** features 层越界，见 §8.4）
- 断点常量只在 `app/breakpoints.dart`（C1）

## 11. 新代码怎么放（速查）

| 你要做的 | 放哪 |
|---|---|
| 新页面 / 功能 | `lib/features/<名>/presentation/` + `controllers/` |
| 新实体 / 用例 / 服务 | `lib/domain/entities/` / `usecases/` / `services/` |
| 新表 / 改 schema | `lib/data/db/database.dart`（**同步 `_ddlXxx` / `_migrate()` / `kSchemaVersion` 三处**） |
| 新 SQL 读 / 写 | `lib/data/repositories/`（**勿在 features 直连**） |
| 可复用控件 | `lib/design_system/` |
| 改颜色 / 主题 | `lib/app/theme/`（改完跑 `theme_contrast_check`） |
| 新测试 | `test/<模块>_test.dart` |
| 本地数据变了 | `ref.invalidateData.bumpXxxMutated()`（见 `AGENTS.md`） |
| 读 DB 的 Provider | `ref.watch(xxxVersionProvider)` 自动刷新 |
| 取色 | `context.colors`（`AppColors`，**别看 `BrandColors`**） |
