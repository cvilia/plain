## 一、结论

推荐产品名 **「青釉」**，英文名 **Celadon**。

理由一句话：**「青釉」把已经定稿的视觉资产（青瓷 × 蜜桃）升格为品牌本体，而「釉」这个词本身同时承载了产品的两条核心承诺——清透可见（账目看得清）与不可渗透（数据不外流）。**

中文名与英文名不是直译关系，而是同一品牌人格的两面：中文取器物质感，英文取国际专有名。出海时英文名可独立使用，不存在拼音障碍。

## 二、命名的三个既有约束

名字不是凭空创作，它必须与三份已经冻结的资产咬合。

**其一，视觉资产已定稿，没有回头路。** 早期高保真稿（现《09-高保真UI.html》已废弃，视觉规格以《14-设计规范·高保真UI.html》与 `theme_registry.dart` 为准）的品牌色为青瓷绿配蜜桃色光斑，设计说明原话是「冷调里透一点暖」，Logo 规范为 78×78、圆角 26px 的方块。名字若与该配色体系不同调，整套视觉资产要么废弃、要么割裂。

**其二，品牌承诺是产品宪法，名字最好能承载它。** 四条承诺——无广告无开屏、数据只存在你的手机里、不申请与记账无关的权限、数据随时导出永不锁定——已写入首启页、商店描述与设置页。这四条的本质是「克制」与「数据主权」。

**其三，核心动作只有一句：「3 秒，记一笔」。** 名字的理想状态是能让用户一听到就联想到这个动作，或者至少不与之冲突。

## 三、竞品名称占用调研（本次命名最大的发现）

**一句话结论：记账赛道的直觉好词已被扫荡干净。任何一个「好听又贴切」的常用词，几乎都已有同类产品占用。**

| 候选方向 | 占用情况 | 与本产品的定位重合度 |
|---|---|---|
| 一笔 | 「一笔账」「一笔 · 私密记账」均在 App Store 在架 | 高——「可完全离线、数据本地存储、无需注册」几近同句 |
| 有数 | 「有数记账」「有数 · 物品记账与个人资产管理」（4.7 分、4563 评分） | 中 |
| 小满 | 「小满记账」「钱小满 · 治愈系项目记账管家」 | 极高——「完全本地化存储、零广告零开屏零弹窗、极速记一笔」 |
| 有余 | 「有余记账」（4.9 分、1.1 万评分，成熟产品） | 高 |
| Jot | 「Jot: Private Budget Tracker」（无账号、无广告、无分析、本地存储） | 极高 |
| 青瓷 | 厦门青瓷游戏（《江南百景图》开发商）品牌占用 | — |
| 拾穗 | 被任务悬赏类低质 App 占用，品牌会被拖累 | — |

由此得出两条硬约束：**一、放弃所有「一笔 / 记一笔 / 有数 / 小满 / 有余」类常用词；二、走独特词或自造词路线**，与小米、腾讯、字节的做法一致——现成好词已被注册完，品牌力来自独特性，而非语义直白。

## 四、候选方案

### 方案 A · 青釉 / Celadon【推荐】

中文「青釉」是青瓷的核心工艺特征——覆盖在瓷胎表面的一层釉。它是视觉资产的直系血亲（青瓷色即釉色），且「釉」的物理属性构成了精确的产品隐喻：**釉让器物清透可见（看得见内部的形与色），又不可渗透（水与污无法进入）。** 这恰好对应产品的两条核心承诺：账目看得清、数据不外流。

英文 Celadon 是青瓷的国际通用专有名词（源自法语，专指中国青瓷）。它在全球消费应用领域无同名，中文名与英文名可各自独立成立，出海时不出现拼音障碍——思路与「抖音 / TikTok」一致。

风险有三：①「釉」读 yòu，需在首启页与商店描述中一次性教育；②厦门青瓷游戏在第 9 类、第 42 类的商标布局须逐一核对，这是本方案唯一的实质性障碍；③文艺调性对 P1 效率型主力人群有理解门槛，需以副标题「青釉 · 本地记账」承载品类。

### 方案 B · 素记 / Plain

「素」直接对应「无广告、无开屏、无理财」的朴素承诺，是四个方案中语义最直白、理解成本最低的一个。中文读音顺、无歧义，天然适合商店描述。

**决策后查证结果（2026-09-29，结论：不可用，详见 §8）。** 中文名与英文名双双存在在先占用：中文「素记」有同名日记类 App（iOS 2.5 / Android 双端在架，长期运营）；英文 Plain 在隐私型记账赛道被「Plainly」「PlainMoney」「Plain Wallet」三款产品密集占用，其中 Plain Wallet 的定位（无广告、无分析、类纸质账簿、数据全本地）与本产品高度重合。

### 方案 C · 青桃 / Pip

中文「青桃」是视觉方案「青瓷 × 蜜桃」的直接合体——青与桃两个字，就是那套配色的中文表达。意象上，「青桃」是尚未成熟的桃子，与「还没攒够、还在长大」的储蓄心态同构，直接对应 P4 情绪价值人群的付费动机（PRD §3 与 F9.4 记账伙伴系统）。

英文 Pip 叠加了三层含义：果核（桃核）、金融术语（外汇最小价格变动单位）、「一点点」。简短、好念、可注册性高。

风险：Pip 是 Python 的包管理器名，在技术圈存在混淆，对 P3 极客人群是负面项；中文「青桃」需确认无同类占用。

### 方案 D · 余白 / Margin

「余白」是东方极简美学的核心概念（留白），与产品的克制调性一致；英文 Margin 在英文语境中同时是「留白」与「财务余量 / 余地」，是四个方案中**中英文语义对应最精确**的一对。

弱项：Margin 是 CSS 属性名，前端圈混淆度高；「余白」建立「记账」心智联系需要较多教育成本。

## 五、决策建议

首选 **方案 A · 青釉 / Celadon**：品牌力最强、与既有视觉资产咬合最紧、出海最顺，隐喻可讲、可写进品牌故事。

次选 **方案 B · 素记 / Plain**：若判断主力人群（P1）对文艺名的接受度不足，或方案 A 商标受阻抗，则退守 B。

## 六、决策后的待办清单

1. **商标检索**：第 9 类（计算机软件）与第 42 类（软件设计与开发），同步核查第 35 / 38 类；优先确认厦门青瓷游戏的注册范围。
2. **域名与包名**：主域 .com 优先，兜底 .app / .cn；包名统一为 com.<品牌>.<产品>。
3. **商店查重与 ASO**：App Store 与主流安卓商店逐一查重；关键词围绕「本地记账、无广告记账、记账导出」布局。
4. **回填文档**：关闭 PRD v1.1 §12 开放问题 #1 并记录决策；《14-设计规范·高保真UI.html》首启页、商店素材、图标规范同步命名。
5. **品牌描述定稿**：为选定名写一段 80 字以内的商店描述首句，直接承载四条承诺。

## 八、决策后查证结果与化解方案（2026-09-29 补）

### 8.1 查证结果

**中文「素记」：已被占用。** 存在同名 App「素记」（又称素记日记），是一款极简日记应用，iOS 版本 2.5（41.3MB）与 Android 包（com.halo.diary、com.admster.suji）双端在架，有微博账号「素记app」与固定联系邮箱，属长期运营的商业化产品。其品牌文案为「不艳丽，不过分。用心感受，写日记的本质。愿简约朴素的素记，能带给您写日记的平静」——与本产品的克制调性同源。

性质判定：**非同类竞品（日记类 vs 记账类），但构成实质品牌占用。** 三项具体影响：① App Store 搜索「素记」时被该产品分流，用户会看到他人页面与评价；② 第 9 类商标存在在先使用，注册近乎无望；③ 该产品已独占「素雅极简」的品牌联想，本产品无法以此建立差异。

**英文 Plain：已被占用。** 在隐私型个人财务赛道，「Plainly」（Puredata OÜ，本地优先 + 云同步付费，与本产品的商业化结构几乎一致）、「PlainMoney - Personal Finance」（无账号、无后端、无分析、截图与语音均在端侧处理）、「Plain Wallet」（无广告、无分析、类纸质账簿、全本地、可选 iCloud）三款产品叠加占用。

### 8.2 化解方案

**首选：中文「素记簿」/ 英文 Daybook。**

「素记簿」在完整保留「素记」二字的前提下，用「簿」同时解决两个问题：其一，构成三字独特组合，商标可注册性大幅提升，与同名日记 App 形成清晰区隔；其二，补足品类语义——「簿」即账簿，直接修补原名最大的弱点（「素记」看不出是记账应用）。读音 sù jì bù 顺口，且「簿」的古意与青瓷视觉调性一致，不产生违和。

英文 Daybook 是会计术语，专指按日登记流水交易的账簿，语义精确对应「簿」，简短、可念、有专业感，与「克制、可信」的品牌调性契合。需注意：Daybook 为常见英文词，占用情况须一并检索。

**备选一：「素记」坚持使用（不推荐）。** 走「同名不同类」路线，App Store 允许同名，但代价是搜索分流、商标无望、长期被误认为日记 App 的附属品。

**备选二：放弃「素记」，保留「素」的内核另取。** 若「素记簿」亦不利，可退至「素账」「素瓷」「素印」等更短组合，或回退到方案 A「青釉 / Celadon」。

### 8.3 决策后的待办清单（修订）

1. **商标检索**：优先确认「素记」在第 9 类的注册状态与「素记日记」的在先权范围；同步检索「素记簿」「素账」「Daybook」。
2. **商店查重**：App Store 与主流安卓商店检索「素记簿」；确认 Daybook 在消费应用领域无同名。
3. **域名与包名**：包名建议 sujibu 或 suji.book 语义串；主域 .com 优先。
4. **回填文档**：名称定稿后关闭 PRD v1.1 §12 开放问题 #1；《14-设计规范·高保真UI.html》首启页、商店素材、图标规范同步命名。
5. **品牌描述定稿**：写一段 80 字以内的商店描述首句，承载四条承诺，并明确与「素记日记」无关联。
